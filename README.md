# JavaScript Basics

A small collection of beginner JavaScript files for practicing basic syntax and running code with Node.js.

## Examples

- `Helloworld.JS` — declares a variable and prints its value.
- `Chapter1_JS_Basic.JS` — logs the result of a simple addition.
- `Chapter3_JS_Engine.js` — prints a "Hello world" test message.

## Run an example

Install [Node.js](https://nodejs.org/) if it is not already installed, then run a file from this directory:

```sh
node Helloworld.JS
```

Replace `Helloworld.JS` with another example filename to run a different file.
